Buttons communicate actions that users can take.<br />
They are typically placed throughout your UI, in places like: dialogs, modal windows, forms, cards or toolbars.

<Canvas of={ButtonStories.Primary} />


## Examples

<br />

### Variants

Use the `variant` attribute to set the button’s variant / color. Default: `primary`<br />
To override the color for an individual button, use the `--ui-button-color` CSS variable.

<Canvas of={ButtonStories.VariantExample} />

### Outlined

Use the `outlined` attribute to set toggle between a filled and outlined variant. Default: `false`<br />

<Canvas of={ButtonStories.OutlinedExample} />

### Sizes

Use the `size` attribute to configure a button’s size. Default: `medium`<br />

<Canvas of={ButtonStories.SizeExample} />

### Icons

To add an icon to buttons, place an `<ui-icon>` element in the slot of the button.<br />
You can configure the location using the `slot` attribute, such as `slot="prefix"`.

<Canvas of={ButtonStories.IconExample} />
