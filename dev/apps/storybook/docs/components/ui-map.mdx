Map is a component for displaying geographical maps from various sources.<br />
It supports multiple layers, tiled and full-image sources, adding markers, and interaction through events.<br />

## Examples

<br />

### Coordinates / zoom

With the `lat` and `lng` attributes, you can adjust the coordinates that is centered on the map.<br />
The `zoom` attribute (a value between 1 and 20) configures the default zoom; `1` is world-view, and `20` street level.

<Canvas of={MapStories.CenterZoomExample} />

### Map Style / options

Using the `mapStyle` attribute, you can provide a URL to a MapLibre `style.json` specification file.<br />
The specification of this JSON file can be found [here](https://maplibre.org/maplibre-style-spec/).<br />

Default: `https://demotiles.maplibre.org/style.json`
